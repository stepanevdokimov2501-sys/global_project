Telegram-бот о глобальном потеплении

Небольшой Telegram-бот на Python (pyTelegramBotAPI), который рассказывает о глобальном потеплении, его причинах, последствиях и способах борьбы с ним. Также умеет присылать случайные факты о климате.

Команды

• /start и /help — приветствие и список команд
• /info — что такое глобальное потепление
• /causes — основные причины
• /effects — последствия для планеты
• /solutions — как можно бороться с проблемой
• /tips — простые советы на каждый день
• /fact — случайный факт

Структура проекта

• bot.py — основной код бота и обработчики команд
• logic.py — логика выбора случайного факта
• config.py — токен бота (перед публикацией лучше вынести в переменные окружения или .env)

Запуск

1. Установите библиотеку: pip install pyTelegramBotAPI
2. Укажите ваш токен в config.py
3. Запустите бота: python bot.py
